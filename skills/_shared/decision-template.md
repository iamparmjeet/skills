# Decision Template (canonical)

Use this from any skill. Do not duplicate variants elsewhere.

```md
## YYYY-MM-DD - [slice/feature]
Decision: [what chosen]
Why: [reason, 1-2 lines]
Alternatives: [what else considered + why rejected]
Tradeoff: [what accepted]
Model: [model/version]
```

One entry per meaningful decision. Code shows what, this shows why.
