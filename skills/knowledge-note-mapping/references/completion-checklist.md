# Completion Checklist — Knowledge Mapping

Copy into PR/diff note or validate before handoff.

- [ ] Source captured with provenance (author, URL, published/captured, timestamp/section for audio/video)
- [ ] Claims extracted (each as one idea; qualifications kept)
- [ ] Existing vault searched — reused/improved existing notes where appropriate
- [ ] New atomic notes created only where concept is reusable outside this source
- [ ] Title/MOC notes have real scope (boundary + branches), not just a list
- [ ] Links express relationship (is a type of / governed by / contrasts with / depends on / application of) — not similarity
- [ ] Evidence status assigned per substantive claim: supported | partly supported | unsupported | contested | not yet verified
- [ ] Strongest authority linked (systematic review/guideline/RFC/official docs/primary research)
- [ ] Uncertainty/limits preserved; no vague label turned into conclusion without actor/action/channel/time/outcome
- [ ] No duplicate notes created
- [ ] YAML/frontmatter, filenames, and source status/movement correct
- [ ] Diff inspected; source note updated with extracted links and processed status
