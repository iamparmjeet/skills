# Interview Prep - Scoring Rubric

## Per-answer scale (1-5)

| Verdict | Meaning | Evidence bar |
|---|---|---|
| 5 | Interview-ready: precise, structured, own example | Quoted answer already uses the vocabulary correctly |
| 4 | Solid: right model, minor gap | Quoted answer correct but missed one edge/tradeoff |
| 3 | Shaky: partial model, needed a prompt | Quoted answer needed your follow-up to get there |
| 2 | Gap: wrong on a core point | Quote shows the misconception; correction logged |
| 1 | Cold: could not engage with the question | User passed, guessed, or answer off-topic |

Score from quoted evidence, never impression. If you cannot quote it, the score is not earned.

## Topic score

Topic score = median of answer scores on that topic, plus a weak-areas list (every topic where any answer scored <= 3).

## Readiness verdict

Per topic, after the drill step:

- **Ready** — topic score >= 4, no lingering weak area, teach-back passed.
- **Shaky** — score 3, or 4+ with an unresolved weak area. Name the exact drill for next session.
- **Gap** — score <= 2. Re-teach before re-grilling; do not declare readiness from drilling alone.

Overall verdict = worst topic verdict, stated plainly ("core JS ready, system design shaky, closures gap").

## Anti-inflation

- Never round up a verdict to spare feelings; a false "ready" costs a real interview.
- Praise is allowed and specific ("that tradeoff framing was exactly right") but never changes a score.
- Timeline pressure (interview in 2 days) shifts strategy to `cram` mode, not scores down.
